# Plotting

The built documentation uses CairoMakie because it can render figures in
continuous integration. GeoInterface-compatible geometry values can also be
used with compatible Makie backends; CairoMakie is the backend used by the
examples, not a requirement of the data model. For a minimal plotting
workflow, see [plot geometries](../how-to/plot-geometries.md), then consult
the [Makie documentation](https://docs.makie.org/stable/) for backend-specific
features.
